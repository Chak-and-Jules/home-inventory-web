## 2026-07-31 - Reverted callback micro-optimizations
**Learning:** Replacing declarative, readable JavaScript methods like `reduce`, `forEach`, or `Object.entries` with verbose imperative loops solely to avoid 'callback overhead' is considered an unacceptable micro-optimization that sacrifices readability for negligible performance gains, and is directly blocked by reviewers.
**Action:** When optimizing arrays, focus exclusively on algorithmic time complexity improvements (e.g., (N \log N)$ to (N)$) and avoid converting purely functional mapping/reducing code into manual loops unless it demonstrably solves a significant bottleneck.
